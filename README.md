# Biker Zone

A responsive motorcycle landing page built from a Figma-style design using HTML, CSS, and Bootstrap. The project focuses on a product-oriented layout with responsive navigation and promotional sections.

## Tech Stack

- HTML5
- CSS3
- Bootstrap 5
- Responsive Web Design

## Highlights

- Responsive navigation
- Motorcycle-focused hero section
- Product presentation
- Promotional content sections
- Bootstrap responsive utilities

## Getting Started

```bash
git clone https://github.com/mdjihad-dev/Biker-Zone.git
cd Biker-Zone
```

Open `index.html` in a browser to view the project.

## Project Focus

Built to practice converting a visual design into a responsive frontend layout and working with Bootstrap's grid and component utilities.
